# Language & RTL

Last verified: 2026-11-24

- The account UI is **English** (`<html lang="en" dir="ltr">`), while group content is mostly Hebrew. Facebook auto-translates
  Hebrew posts in the DOM ("See original"). graphql carries the original `message.text` plus `translation.message.text`.
- Search queries in Hebrew work (`/search/top?q=%D7%93…`). Titles wrap them in LRM/RLM marks (`‎דירה להשכרה‎`).
- Localized strings we key off (English UI verified, Hebrew **Unverified**):
  | Meaning | English | Hebrew |
  |---|---|---|
  | expand text | See more | ראה עוד |
  | comments button | `<N> comments` / `1 comment` | `<N> תגובות` / `תגובה אחת` |
  | public group | Public group / `Public · …` | קבוצה ציבורית |
  | private group | Private group | קבוצה פרטית |
- Member counts are localized strings ("139.8K members"). Parse defensively.
- Recommendation: keep the account's UI language fixed (whatever it is now). Changing it changes every text marker.
